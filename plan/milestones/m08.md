# M8 Walk away

## Goal

Let a test author start arma-grappling-hook's suite and walk away, as PRD scenario 5 says, and come back to a result whatever happened to the run.

## Demo

`shakedown run --setup dedicated-2` runs every arma-grappling-hook check written so far, starting and stopping its own session; a second run is stopped with Ctrl+C in its second check; both leave a valid result file and no game process.

## Stories

- `US-033` (feature) Run the full suite and walk away
- `US-034` (system fail) A run is stopped by hand
- `US-036` (feature) Stopping a session leaves nothing running
- `US-063` (system fail) A run reaches its runner ceiling

## What it builds

- Stopping a run by hand: `run stop`, `run_stop`, Ctrl+C and Ctrl+Break (`RUN-05`), with `not_run` and `stopped_reason`.
- The run's runner ceiling (`RUN-06`).
- `session stop` and its tool releasing every port and mission copy (`STP-04`), and a run that started its session stopping it whatever ended the run (`STP-02`).
- `docs/`: running a suite unattended and reading a stopped run's result.

## Spikes

None.

## Exit criteria

1. `US-033`, `US-034`, `US-036` and `US-063` pass their acceptance criteria on the test machine.
2. The demo leaves no `arma3_x64` or `arma3server_x64` process and no port from the base port to the base port plus 4 held.
3. Every check and test it adds carries the story or requirement ID it proves (`NFR-MT-02`), the gates of `NFR-MT-03` pass, and `docs/` say how to use what it built.
4. The owner has run the demo on the Windows test machine.

## Left out

A machine lost or crashed during the run (M9).
