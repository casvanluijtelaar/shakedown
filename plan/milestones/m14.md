# M14 Reload without a game restart

## Goal

Close the gap against G2 for mod code (`DEF-21`). Every change of a mod's code is a game restart of 46 to 82 s (`NFR-PF-02`), while the PRD's loop is under 30 s. arma-grappling-hook's next milestones are mostly mod code (the thrown hook, climbing), so each edit of theirs pays a game start. The M10 port did not exercise a reload of that mod (exit criterion 3, waived with the demo).

## Demo

A changed `PREP` function of arma-grappling-hook is reloaded into a running `dedicated-cba` session without a game restart, and `US-009-1-freed` rerun on it passes with the new code, from the save to the verdict in under 30 s.

## Stories

- `US-081` (feature) A changed function reaches a running dedicated session without a game restart
- `US-082` (system fail) The game still holds the changed file

## What it builds

- Whichever way `SPK-19` passes: a forced release of the file, or ACE3's layout of one folder reached through two links, in `RLD-02`, `P-08`, `RLD-06` and `docs/`.
- The fallback to a game restart when a machine still holds a changed file, with its reason (`RLD-02`, `RLD-03`).
- `RLD-02`, `P-08`, `NFR-PF-01`, `NFR-PF-02`, `US-054`, `US-055` and `FIX-03` edited to the level the spike allows.

## Spikes

- **`SPK-19`**, whole, runs first; its pass condition is in `spec/06-open-questions.md`. If it fails: M14 builds nothing and is closed as not needed, `RLD-02` keeps every mod `.sqf` at `game-restart`, and `DEF-21`'s third option, staging and text injection at a mission restart, goes to the owner with the spike's result.

## Exit criteria

1. `US-081` and `US-082` pass their acceptance criteria on the test machine.
2. `DEF-21`'s acceptance criteria hold.
3. The spikes' results are in `research/`, and the spec is edited in place to what they found.
4. Every check and test it adds carries the story or requirement ID it proves (`NFR-MT-02`), the gates of `NFR-MT-03` pass, and `docs/` say how to use what it built.
5. The owner has run the demo on the Windows test machine.

## Left out

- `DEF-21`'s third option, staging and text injection, unless the owner chooses it after `SPK-19` fails.
- `BIS_fnc_recompile` mid-mission (`SPK-09`) beyond what the level the spike allows needs.
