# M7 Reload inside the mission

## Goal

Give a mod whose functions are not final the edit-and-check loop of G2: under 30 s from a reload to a check's verdict, with no restart, in singleplayer and on a dedicated server. A recompile inside the mission needs a changed file to reach a running game, which the game's hold on every mod file it has read prevents (`SPK-08`, research `27-spikes-reload.md`), so level A waits for `DEF-21`; until then `US-054` is met by the game restart of M6.

## Demo

With a dedicated session of two clients, the fixture's `fn_version.sqf` changed from `"1"` to `"2"` is reloaded with level `game-restart`, and a check tagged with a finding sees `"2"` on every machine, within `NFR-PF-02`'s target plus 10 s from the reload to its outcome.

## Stories

- `US-054` (feature) Reload a changed function and rerun the checks a finding names
- `US-058` (mistake) A reload asked while a run is active

## What it builds

- Level A of `P-08`, `BIS_fnc_recompile` on every machine verified by the hash of each function's source, and `reload: partial` on the checks after it (`RLD-05`, `DM-08`), only once `DEF-21` lets a changed file reach a running game.
- A reload or reset asked during a run, reload or reset is refused with `session-busy` (`RLD-01`).
- `docs/`: which changes reload inside the mission, and what `partial` means.

## Spikes

- **`SPK-09`** runs only once `DEF-21` lets a changed file reach a running game; research 27 met its pass condition once in singleplayer, on a file the game had let go of. Its pass condition is in `spec/06-open-questions.md`. If it fails: `RLD-02` keeps no level-A row for mod code, and `RLD-05` and `DM-08` stay moot.

## Exit criteria

1. `US-054` and `US-058` pass their acceptance criteria on the test machine.
2. `NFR-PF-02` holds in singleplayer and on a dedicated session with two clients.
3. If `SPK-09` ran, its result is in `research/`, and the spec is edited in place to what it found.
4. Every check and test it adds carries the story or requirement ID it proves (`NFR-MT-02`), the gates of `NFR-MT-03` pass, and `docs/` say how to use what it built.
5. The owner has run the demo on the Windows test machine.

## Left out

A reload inside the mission or by a mission restart, until `DEF-21` finds a way round the game's hold on the files it read.
