## Runs that were not green on the first try

- The first runs of the `runner.json` ACL check passed the file's path to PowerShell as an argument of `-Command`, which a script given that way does not receive, so they read no rules. The check now puts the path into the script; it then failed on the ACL itself, 3 of 3.
- The first round: the `US-053` `unknown-process` check failed because `audit.jsonl` held the marker's name. The line was the harness's own `exec` that asks every machine whether the marker is nil; the check looks for the intruder's assignment instead.

## Findings

`m05-1`, for the developer: `runner.json` is readable by the Administrators group besides the current user, where `SEC-02`, `INT-WIN-03` and `spec/contract/cli.md` promise the current user only. It is open.
