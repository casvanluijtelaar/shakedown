# M3 Script errors and logs: coverage

The run: `python acceptance/run.py` at 17:07Z, every check once, against the framework installed from `444bdfe`, CBA_A3 from Steam Workshop item 450814997 and arma-grappling-hook's built mod as it stood. It took eleven minutes: 117 checks, 117 passed. By milestone: M3 21 of 21, and M0 to M2 96 of 96. Before it, the M3 checks alone ran once and then three times in one dedicated session (`--repeat 3`); every story check passed 3 of 3.

The M3 round wrote no finding. A check of the round asserted that an error the RPT scan found gives its file without a leading backslash; it failed because the check's own `File` line had one, which the engine does not write (`File skdfx\addons\main\functions\fn_throw.sqf..., line 4` in the same RPTs). The line was fixed in the check.

## How the Steam identity was searched

The checks read the Steam ID and the account and persona names from the machine at run time, as `INT-STM-04` says, and search for the Steam ID, any 17-digit number starting `7656119`, and each name as a whole word, case-sensitive (`LOG-02`). They searched every file of every run folder, every RPT of every stopped session, every file of the session folders outside the profile folders, `runner.log`, the output of `run` and of `logs`. None held any of them; the RPTs and the files `logs` stores show `<steamid>` and `<steamname>` where the game wrote them.
