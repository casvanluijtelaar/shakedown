# M4 Agent tools: coverage

The run: `python acceptance/run.py` at 19:34Z, every check once, against the framework installed from `9d1bda2`, CBA_A3 from Steam Workshop item 450814997 and arma-grappling-hook's built mod as it stood. It took fifteen minutes: 171 checks, 171 passed. By milestone: M4 54 of 54, and M0 to M3 117 of 117. Before it, the M4 checks ran once and then three times in each session (`--repeat 3`): every story check passed 3 of 3 except one check of the tester's own, below.

The tools are driven over their protocol, never through Claude Code: the harness starts `shakedown mcp` from the generated project's `.mcp.json` (the one `docs/agent-tools.md` gives), with the install folder on `PATH`, and speaks JSON-RPC 2.0 to it on stdio, with protocol version `2025-06-18`, progress tokens and `notifications/cancelled`.

## Runs that were not green on the first try

- The first M4 round: two offline checks read the whole project's `list_checks` as checks, but that result passes 20,000 characters and comes as `result_path`, as `AGT-07` says; the checks read the file. Two `US-062` checks judged `duration_s`, which holds the wait for errors in flight; they judge `reason.at`. The `AGT-02` schema check read answers two other checks had masked in place; those work on copies.
- The flake round: the `US-014` compile check ended `script-error` in three of four executions, from its own `compile "1 +"` on the lead machine racing the target's compile failure. The check expects its own error with `skd_fnc_expectError`, and passed 3 of 3 after that.
- The first full run: `CFG-02` did not expect the `.mcp.json` the harness writes, and `NFR-RL-05` did not see the runs started through `run_start`; both were the harness's. In that run the game raised `Undefined variable in expression: tsw_camtargetunit` on `p1` three times during the 55 s check of `US-050`, in the singleplayer session in which `RST-05` had killed the player earlier; the framework listed the errors in that execution and failed it `script-error`, as `ERR-03` says.

## Findings

`m04-1`, for the writer: `AGT-07` puts a long tool result in the session or run folder, while `spec/contract/mcp-tools.md` and `docs/agent-tools.md` put it in `.shakedown/results/`, where the server writes it. The round found no defect of the framework.
