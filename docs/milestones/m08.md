# M8 Walk away: report

M8 is complete, at version `0.0.9`. The M8 build did not raise the workspace version, so its binaries report `0.0.8`; M9's build sets `0.0.10`. Exit criteria 1, 2 and 3 are met, with the Rust jobs of GitHub Actions failing as criterion 3 says. Criterion 2 was checked on the fixture suite, as the demo was not run. The owner waived the demo of criterion 4, and it was not run.

## What it built

| Part | Where | What it does |

## Decisions written into the spec

- `RUN-05`, `P-10` and both contracts: what a stop by hand ends, terminates and writes, `run_stop`, and `session stop` during a run with `session-stopped`.
- `RUN-06`: the runner ceiling is the sum of the checks' timeouts plus 60 s.
- `STP-04`: `session stop` returns only once no process runs and no port is held.

## The demo

The milestone's demo: `shakedown run --setup dedicated-2` runs every arma-grappling-hook check written so far, starting and stopping its own session. A second run is stopped with Ctrl+C in its second check. Both leave a valid result file and no game process.

The owner waived this demo on 2026-11-13, and it was not run. The acceptance round drove the same two runs on a suite of three fixture checks with the setup `dedicated-2`.

## Acceptance

The test developer's round found no defect and no document gap, and wrote no finding. The M8 round, against the framework from `f6b094f`, passed 48 of 48: the 16 M8 checks three times. Each repeat ran one `run --setup dedicated-2` to its end, one stopped by Ctrl+C, one `run --setup sp` that reached its runner ceiling, and a `session stop` and a `session_stop`. One running singleplayer session took stops by Ctrl+C, Ctrl+Break, `run stop` and `run_stop` and the ceiling runs by command and by tool. `run stop` returned in 2.0 to 2.1 s with the result file written; `session stop` in 0.8 to 1.0 s with nothing left; the ceiling stopped a run 68.0 s after its first check started, all three times. The full run at `202174d`, against the framework from `f6b094f`, passed 243 of 243, the 16 M8 checks among them. The runs are in [the M8 coverage](../../acceptance/coverage/m08.md).

## Left out

- A reset a stop cut short goes on in the game until it ends or reaches its 15 s ceiling (`DEF-23`, no milestone yet).
- The acceptance round did not drive `RUN-05`'s promises beyond the stories' criteria: a Ctrl+C while `run --setup` still starts its session, a second Ctrl+C, a `session stop` during a run, and that the stopped check's body is terminated in the game.
- A machine lost or crashed during a run is M9.
