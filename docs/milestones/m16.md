# M16 A start that explains itself: report

M16 is complete, at version `0.1.6`. Exit criteria 2 to 4 are met, and criterion 1 for every acceptance criterion the test machine can reach without a person. Two parts of criterion 1 needed the owner: `US-088`, which needs a rendered client window, and `US-085` with Steam logged out. On 2026-11-23 the owner waived both looks and the demo of criterion 5, and none of them was run.

The M16 build set the workspace version to `0.1.6`. M16 closes after M17 to M19's builds, which raised the workspace version ahead for M19's pre-release, so the binaries built at the close commit report `0.2.0-rc.1`, not `0.1.6`.

## What it built

| Part | Where | What it does |
|---|---|---|
| The full environment check | `crates/shakedown/` | `ENV-01`, `SES-03`, `INT-STM-01`, `INT-STM-04`: before any game starts, Steam's login, every mod folder, the session's ports and the free space of the project's drive are checked, and every gap is named in one message, by the command line and by `session_start`. |
| A mod in another version | `crates/shakedown/`, `spec/contract/cli.md` | `US-086`, `INT-STM-03`: the mod key `version`, with its `patch`, stops a start whose machines load that mod in another version, naming the mod, the machine, the version found and the one wanted. |
| The reason of a failed start | `crates/shakedown/` | `SES-10`, `DEF-29`: `session.json` keeps the reason `session start` printed, with its machine and RPT tail, before and after `session stop`; at the start ceiling the reason names the machine that got least far, and says when it wrote no RPT line (`SES-04`). |
| A client sent to another server | `addon/`, `crates/shakedown/` | `SEC-05`, `US-088`: the in-game agent compares its server's host name with the session's at each mission start; a client on another server is ended, the check ends `fail` / `check-error`, and the machine is lost as `foreign-server`. |
| The docs | `docs/starting-and-failed-starts.md`, `docs/project-file.md`, `docs/sessions-and-the-runner.md` | Why a start is refused or fails, pinning a mod's version, and the reason a failed start keeps. |

## The spike

`SPK-20` failed ([research 32](../../research/32-spike-connect-times.md)): a connect ceiling of twice the slowest launch-to-connect time does not fit under 90 s, and one singleplayer start hung in the engine's graphics start for the whole start ceiling. `SES-10`'s connect ceiling is dropped, `US-087`'s first criterion is edited to the start ceiling, and `DEF-28` stays open with the `preStart` option. The trials of moving a client to another server are in [research 33](../../research/33-client-to-another-server.md).

## Tests

With the game, after `python tools/install.py`: `cargo test -p shakedown --test m16 -- --ignored --nocapture --test-threads=1`, with `us_085_env_01_every_gap_is_named_at_once`, `us_086_env_01_a_mod_in_another_version_fails_the_start`, `us_087_ses_10_a_hung_client_fails_the_start_and_the_reason_is_kept` and `us_088_sec_05_a_client_sent_to_another_server_is_ended`. The last drives a client out of its mission through the pause menu's Abort, which does nothing without a rendered window, so it is the owner's look and fails at its wait when the owner is not connected through Shadow PC.

No repeated-demo test was run at the close: no exit criterion of M16 asks for one apart from the demo the owner waived.

## Decisions written into the spec

- `ENV-01`, `SES-03`, `INT-STM-01`: the full environment check before a start, every gap named at once, free space included.
- `ENV-01`, `CFG-01` and `spec/contract/cli.md`: the mod key `version`, which needs `patch`, compared with the version each machine loaded.
- `SES-10`, `SES-04`: `session.json` keeps a failed start's reason; at the start ceiling the reason names the machine that got least far. No connect ceiling.
- `SEC-05`, `P-07`, `DM-04` and `spec/contract/result-file.md`: a client on another server is ended, the check ends `check-error`, and `foreign-server` is a way a machine is lost.

## The demo

The milestone's demo: a start with Steam logged out, a mod folder missing and a port taken naming all three; ACE's `version` set wrong in arma-grappling-hook's `shakedown.toml`; a client suspended at its launch failing the start at the ceiling. The owner waived it on 2026-11-23, and it was not run. The acceptance round drove the missing folder, the held port, the full drive, the wrong version and the hung client on the fixtures.

## Acceptance

The M16 round, on 2026-11-21 at `2034d04`, passed every M16 check, and the 38 earlier checks once, with no finding. Its trial runs before it saw one failure of the check's own (a start ceiling too short on a cold machine, fixed in the check) and one singleplayer client that never connected, the hang of `DEF-28`.

## Left out

- A connect ceiling of any kind (`DEF-28`, open, no milestone yet), and pinning or downloading a Workshop mod's version.
- Not deferred, from the round: a `.shakedown` folder that cannot be created answers exit 5 before the environment check rather than a gap in the one message; the RPT-tail form of `US-087` for a client that hung after writing RPT lines was not seen.
