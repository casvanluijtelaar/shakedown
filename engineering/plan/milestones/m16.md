# M16 A start that explains itself

## Goal

Make a start that cannot work say so early and fully. The test rounds of M6 to M8 met a client that hung and held `session start` for its whole 180 s (`DEF-28`) and a failed start whose `session.json` held no reason (`DEF-29`); the M10 port loads CBA and ACE from the Workshop, which updates them on its own (`INT-STM-03`), while the reset's ACE heal is pinned to the ACE version it was checked against (`INT-ACE-02`).

## Demo

A start with Steam logged out, a mod folder missing and a port taken names all three at once; with ACE's `version` set to another version in arma-grappling-hook's `shakedown.toml`, `session start --setup sp-cba-ace` fails naming ACE, the version found and the one wanted; a client suspended at its launch fails the start at the start ceiling, naming it, and `session.json` keeps the reason.

## Stories

- `US-085` (feature) The environment is checked in full before a start, every gap at once
- `US-086` (error) A mod loaded in another version than the project names
- `US-087` (system fail) A client that hangs in its start fails it, and the reason is kept
- `US-088` (mistake) A check sends a client to another server

## What it builds

- The full check of `ENV-01` in the start, every gap listed, and the mod `version` key in the CLI contract.
- `SPK-20`, and the reason in `session.json` of `SES-10` (`DEF-29`); `SPK-20` failed, so there is no connect ceiling and `DEF-28` stays open (research `32-spike-connect-times.md`). At the start ceiling the reason names the machine that got least far (`SES-04`).
- The check of `SEC-05` in the in-game agent, comparing its server's host name with the session's.
- `docs/`: why a start is refused or fails, and pinning a mod's version.

## Spikes

- **`SPK-20`**, whole, runs before the connect ceiling; its pass condition is in `engineering/spec/06-open-questions.md`. If it fails: `SES-10`'s connect ceiling is dropped, a hung client keeps waiting for the start ceiling, `DEF-28` stays open and `US-087`'s first criterion is edited to the start ceiling; the reason in `session.json` is built either way.

## Exit criteria

1. `US-085`, `US-086`, `US-087` and `US-088` pass their acceptance criteria on a Windows machine with Arma 3.
2. `DEF-29`'s acceptance criteria hold.
3. The spikes' results are in `engineering/research/`, and the spec is edited in place to what they found.
4. Every check and test it adds carries the story or requirement ID it proves (`NFR-MT-02`), the gates of `NFR-MT-03` pass, and `docs/` say how to use what it built.
5. The owner has run the demo on a Windows machine with Arma 3.

## Left out

- Pinning or downloading a Workshop mod's version: the start only refuses a version the project does not name.
- A connect ceiling of any kind (`DEF-28`), since `SPK-20` failed.
