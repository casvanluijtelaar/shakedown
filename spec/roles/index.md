# Roles

* [Test author](test-author.md) - Writes acceptance checks in SQF for a mod from its user stories, without reading the mod's source, runs them and reads the verdicts; a person or an AI agent.
* [Mod developer](mod-developer.md) - Changes a mod's code and reloads it into a running session to rerun the checks a finding names; a person or an AI agent.
* [Manual tester](manual-tester.md) - A person who does the visual and feel checks no script can judge, put in the right situation by the framework.
